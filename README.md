# Мини-синхронизатор заявок — PHP 8.3

Результат: https://test-work-production.up.railway.app/api/clients

GET /api/clients (также /) получает актуальные заявки из https://test.ooobs.ru/api/orders и возвращает строго clients и stats.

## Правила

Удаляем форматирующие символы. К 10 цифрам добавляем 7; начальную 8 в 11 цифрах заменяем на 7. Принимаем только итоговые 11 цифр с начальной 7.
Для дублей выбираем максимальный amount, при равенстве — более поздний created_at. Все поля клиента берутся из выбранной записи. Сортируем клиентов по телефону.
duplicates_merged = количество валидных заявок минус unique. Невалидные телефоны считаются отдельно.
Каждый запрос вычисляет результат заново, без накопления данных: одинаковый источник даёт одинаковый JSON.
При ошибке API возвращаем HTTP 502 вместо фиктивного успешного результата.

## Запуск

```sh
php tests/sync_test.php
php -S localhost:8080 -t public public/index.php
```

Railway автоматически собирает Dockerfile (официальный PHP 8.3 + Apache). Публичный домен направляется на порт 80. Healthcheck: /healthz.

## Секреты и выбор решения

Секреты задаются переменными окружения Railway и не попадают в Git; .env исключён. ORDERS_API_URL позволяет изменить источник; текущий API не требует ключа.
Чистый PHP без фреймворка и БД: один проход по заявкам, минимум зависимостей, отсутствие накопления дублей и воспроизводимый деплой.
